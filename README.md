# 葵・夏日送信

在夏末的小鎮，替人們送幾封信，也慢慢認識身邊的人。

離線單人、第三人稱的治癒休閒小遊戲。走路送信、和居民聊天、一起搬花盆，經過一場雨，再坐下來聽聽小鎮的聲音。紙風車是可選的小故事。

## 下載與開始

[下載 Windows 安裝版 2.2.0](https://github.com/jiukwaii/aoi-summer-letter-releases/releases/download/v2.2.0/Aoi-SummerLetter-Setup-2.2.0.exe)

Windows 10/11、64位元電腦。執行安裝程式後，從開始功能表開啟「葵・夏日送信」，選「開始新的夏日」。不需要安裝 Godot，也不需要帳號或網路連線。手機與 Mac 無法執行此 Windows 版本。

WASD 移動、滑鼠轉動鏡頭、Shift 輕跑、E 互動、H 提示、M 地圖、Esc 暫停。

## 版本與回報

本版包含三天故事與主角開始頁。完成後仍可在鎮上活動。存檔在 `%APPDATA%/Aoi-SummerLetter-2.2/`，卸載會保留進度。

已進行自動流程、實際渲染與安裝/卸載測試；不代表所有電腦硬體和新玩家體驗均已驗證。人物手指接觸仍有精修空間。程式尚未購買數位簽章，Windows 可能顯示未知發行者。

遇到問題，請在 Issues 記下第幾天、最後對話的人、畫面提示和操作步驟，避免附上私人存檔路徑或個人資料。
